# SAP FBS Quote Compliance & DHI Flag Resolver

A Joule Work Desktop skill for SAP Field Business Support (FBS) / GCF teams.

Analyses Harmony quotes for compliance issues: DHI flags, DOA thresholds,
SWAP/C2CEP rules, deal model, approval routing, and BOM completeness.
Produces a traffic light checklist and a step-by-step action plan.

## How to use

Say any of these in Joule Work Desktop:
- "Check my quote"
- "Is this compliant?"
- "What DHI flags will trigger?"
- Or upload a Harmony quote PDF or Excel BOM directly
